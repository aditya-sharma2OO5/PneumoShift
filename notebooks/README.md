# PneumoShift Exploratory and Reporting Notebooks

This directory houses reproducible analysis notebooks:
- `01_data_audit.ipynb`: Explores patient demographics, label prevalence, AP/PA view distributions, and image intensity checks across NIH and CheXpert cohorts.
- `02_results_overview.ipynb`: Interactive visualization of in-domain vs. cross-domain generalization gaps, ECE calibration before and after recalibration, and threshold transfer degradation.
- `03_xai_gallery.ipynb`: Qualitative and quantitative Grad-CAM galleries (confident-correct, confident-wrong, borderline cases) and failure mode analysis.
